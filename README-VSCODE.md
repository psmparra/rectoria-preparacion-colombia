# Ejecutar en Visual Studio Code

1. Abre esta carpeta completa en Visual Studio Code.
2. Abre `rectoria-vscode.html`.
3. Haz clic derecho sobre el archivo y selecciona **Open with Live Server**.
4. Si no aparece esa opción, instala la extensión gratuita **Live Server** de Ritwick Dey. También puedes abrir el archivo directamente en Chrome o Edge.

Esta versión está autocontenida: el diseño, la lógica y las 140 preguntas están dentro de `rectoria-vscode.html`. No necesita Node, Python, npm ni conexión a Internet.

El progreso se guarda en el navegador. Usa **Exportar mis datos** antes de borrar la carpeta, cambiar de navegador o limpiar los datos del sitio.
